# CataTower
Un jeu de société open source pour 2 à 5 joueurs (age 8+). Empilez les blocs, marquez des points, activez des effets et survivez aux cartes malus - mais ne soyez pas la personne qui fera tomber la tour

## 🎮 Qu'est ce que CataTower?
CataTower est un jeu de société open source que vous pouvez imprimer en 3D pour jouer chez vous. Il combine:

- Dextérité — équilibrez les blocs toujours plus instables.
- Stratégie — choisissez votre méthode pour marquer le plus de points.
- Chaos — déclenchez des effets et malus pour pimenter le jeu.

Jouez en famille ou entre amis à la version standard ou explorez le mode soirée 🍻 pour en faire un jeu à boire!

## 🚀 Guide rapide pour jouer
1. Imprimez les blocs et le dé → utilisez les fichiers .bgcode pour directement imprimer en 3D.
2. Imprimez les cartes → cartes effets et malus à découper (et plastifier si besoin).
3. Lisez les règles → format PDF disponible.
4. Prenez une boite pour ranger les pièces et vous en servir comme base de la tour.
4. Commencez à empiler en esperant que la tour survive.
