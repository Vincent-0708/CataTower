## 🖨️ Printing Instructions
Print the different files on a 3D printer with filaments of the color specified in the file name

NB: The printing machine I used is an [Original Prusa MINI+](https://www.prusa3d.com/fr/categorie/original-prusa-mini/) with 0.4mm nozzle
