# 🍻 Mode Soirée
Transformez CataTower en le jeu parfait pour vos soirées! Avec seulement quelques modification, il devient un jeu à boire:

## 🎮 Adaptation des règles

Ajoutez aux cartes du mode standard les cartes effet et malus avec le symbole 🍺 sur le verso.

Il n'y a plus de compte de points, dès que vous réussissez à placer un bloc sur la tour:

    🟩 Vert → Distribuez une gorgée à la personne de votre choix

    🟦 Bleu → Distribuez 2 gorgées

    🟥 Rouge → Distribuez 3 gorgées

Si vous faites tomber la tour, vous devez boire un nombre de gorgées égal au nombre de blocs qui sont tombés. A la votre... ou bon courage!

## 🖨️ Instructions d'impression
Imprimer les cartes sur une feuille A4, orientation portrait, recto-verso (retourner sur bord long)
