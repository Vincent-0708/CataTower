# 🍻 Party Mode — Drinking Game Variant
Turn CataTower into the ultimate party game! With just a few tweaks, your stacking challenge becomes a hilarious drinking game:

## 🎮 Rule Changes

Shuffle in the special Effect and Malus cards marked with a 🍺 on the back.

There is no point account anymore, whenever you successfully place a block:

    🟩 Green → Give 1 sip to the player of your choice

    🟦 Blue → Give 2 sips

    🟥 Red → Give 3 sips

If you make the tower collapse, you must drink a number of sips equal to the fallen blocks. Cheers… or condolences!

## 🖨️ Printing Instructions

Print the special cards on A4 paper, portrait orientation, double-sided (flip on long edge).
